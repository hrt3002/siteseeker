#Overview

This repository contains the SiteSeeker's model, a fine-tuned YOLOv8 model developed to detect potential mosquito breeding sites such as drainage, stagnant water, garbage, and containers. The model classifies the breeding grounds into Artificial (e.g., plastic containers, discarded tires) and Natural (e.g., puddles, tree holes, coconut shells). The purpose of this model is to support early intervention in preventing mosquito-borne disease by providing accurate and real-time detection of potential mosquito breeding sites.
